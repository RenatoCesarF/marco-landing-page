# Marco — landing page

Landing page oficial do Marco, construída com Astro e gerada como site estático.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

O site pronto para publicação será gerado em `dist/`.

## Preview do build

```bash
npm run preview
```

## Downloads

Quando os instaladores estiverem disponíveis, adicione-os em `public/downloads/` usando estes nomes:

- `Marco-macOS.dmg`
- `Marco-Windows.exe`
- `Marco-Linux.AppImage`

## Deploy

Em serviços como Vercel, Netlify ou Cloudflare Pages, use:

- Comando de build: `npm run build`
- Diretório de publicação: `dist`
